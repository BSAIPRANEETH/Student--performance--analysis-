# Student Performance & Data Analysis System

A beginner-friendly Python project that processes student scores, calculates averages, assigns grades, and identifies the top performer.

## Technologies
- Python 3
- Lists and dictionaries
- Functions
- Conditional statements
- Basic data validation concepts

## How to run
1. Install Python 3.
2. Download or clone this repository.
3. Run:
   `python student_performance.py`

## What I learned

- Writing reusable functions
- Calculating and transforming data
- Producing readable console reports
- Basic error-prevention and clean code practices
